# Recipe App

A simple web application for creating and saving recipes manually, built with Python and Flask.

## Prerequisites

- Python 3.x
- pip (Python package manager)

## Installation

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   cd <your-repo-directory>
   ```

2. **Install dependencies:**
   ```bash
   pip install flask
   ```

## Running the App

1. **Start the server:**
   ```bash
   python3 app.py
   ```

2. **View in your browser:**
   Open [http://127.0.0.1:5000](http://127.0.0.1:5000) in your web browser.

## Usage

- Click **"+ Add New Recipe"** to create a new recipe.
- Fill out the title, prep time, cook time, and servings.
- Add ingredients and steps using the dynamic form rows.
- Click **"Save Recipe"** to store it in the database.
- View your saved recipes on the home page.
